## 可重現指令

不依賴第三方套件的核心測試：

```bash
npm test
DB_PATH=/path/to/test.sqlite node scripts/admin.js check
```

可選的V4 DOM整合測試需本機另有jsdom 26.1.0及授權的原V4檔案，兩者都不提交Git：

```bash
V4_SOURCE=/private/JPLUS_V4.html \
JPLUS_JSDOM_PATH=/private/qa/node_modules/jsdom/lib/api.js \
node scripts/v4-smoke.js
```

腳本會建立隔離暫存資料庫，交易憑證與新增核銷均為合成測試，結束後刪除暫存庫；不連接正式資料庫。jsdom驗證的是DOM與操作邏輯，不會驗證CSS視覺排版、瀏覽器CSP實際執行或手機觸控。
